# Quantum Cognition Research Portfolio

A single page comparing two independent projects that both used
quantum-cognition concepts, honestly:

- **governance-playground** — builds an entanglement-based simulation
  engine for geopolitical decision modeling, then validates that the
  engine's mechanics behave as quantum math predicts when driven by real
  logged decisions.
- **quantum-dating-research** — skips modeling entirely and tests the same
  theoretical claims (order effects, entanglement) directly against real,
  unmediated human behavioral data (8,378 real speed dates).

The point of this page: the two projects test different kinds of claims
(mechanism validation vs. direct empirical test), and they diverge on
entanglement specifically — worth stating plainly rather than blurring into
one triumphant "quantum cognition confirmed" narrative.

Run `portfolio.html` directly in a browser, or see the published artifact.
